# North Star Bakery — Touchstone 3

Four HTML pages and one shared CSS file.

## REQUIRED: Add Sophia media assets
Download **Bakery_c.zip** from the Sophia client scenario and extract its image/audio/video files into `assets/` beside these HTML files. The download was not accessible in this environment, so assets are not bundled. The website references the exact filenames supplied by Sophia.

## Preview
Open `index.html` in your browser or launch Live Server in your IDE. Test navigation and resize to mobile and desktop widths.

## Publish
Create a PUBLIC GitHub repository, upload all four HTML files, `styles.css`, and the `assets/` directory. Add your actual repository and preview URLs to the design explanation. GitHub Pages can provide a preview URL if enabled.

## Notes
Business hours, location, pricing, and descriptions are sample content, not verified bakery facts. The form is a demonstration and does not deliver messages; a backend is required for live submissions. Capture a screenshot of your styled homepage and insert it into the Word document before submission.
