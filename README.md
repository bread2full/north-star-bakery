# North Star Bakery — Touchstone 3

Four HTML pages, shared CSS and official Sophia bakery images and audio.

Open index.html or publish with GitHub Pages. All image and audio assets are in assets/.


## Touchstone 4 JavaScript
The Products page now includes favorites saved to localStorage. The Contact page has JavaScript validation and remembers the request type on this device. The form is a demonstration only and does not transmit orders.

To test: select favorites on Products, refresh, and confirm selections remain. On Contact, click Review request with empty fields to see errors, correct the fields, and try again. Change Request type and refresh to confirm it is remembered.
